# Alerta Dengue Cali
 
Producto de datos para la estimación semanal de casos de dengue y la predicción de brotes
en Santiago de Cali, con datos epidemiológicos, poblacionales y climáticos de 2020 a 2025.
 
**Autores:** Samuel Acevedo Mambuscay (2216646) y Luis Carlos Tez (2216702)
Diplomado en Inteligencia Artificial y Ciencia de Datos — Universidad Libre, seccional Cali
 
## Instalación
 
    python3 -m venv .venv
    source .venv/bin/activate
    make install
